# Телефон — винахід XIX століття

Інтерактивна шкільна презентація (9 повноекранних секцій) на React + Vite +
TypeScript зі звичайним CSS. Без сторонніх бібліотек, без backend.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Збірка та перегляд продакшн-версії:

```bash
npm run build
npm run preview
```

## Керування

- прокрутка мишею або трекпадом (секції прилипають до екрана, якщо вміст
  вміщується; довгі секції прокручуються вільно);
- клавіші `↑` / `↓` (`PageUp` / `PageDown`, `Home` / `End`);
- індикатор праворуч (на телефоні — знизу) з номерами `01`–`09`.

## Структура

```
src/App.tsx               — усі секції, інтерактив і дані
src/styles.css            — тема, анімації, адаптивність
src/main.tsx              — точка входу
public/images/*.jpg       — історичні фотографії (локально, без інтернету)
public/images/CREDITS.md  — джерела та ліцензії зображень
```
